# Task Manager Web App

This is a simple task manager web application built using HTML, CSS, and Python. The application helps users organize and manage daily tasks through a clean and user-friendly interface.

## Features

- Add and manage tasks
- Simple and responsive design
- Easy-to-use interface
- Built with Python backend

## Technologies Used

- HTML
- CSS
- Python

## How to Run

1. Clone the repository

```bash
git clone https://github.com/gokila-12/Task-manager.git
```

2. Open the project folder

```bash
cd Task-manager
```

3. Install required packages

```bash
pip install -r requirements.txt
```

4. Run the application

```bash
python app.py
```

## About

This project was created to practice web development using Python along with HTML and CSS.
